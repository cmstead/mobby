Mobby the Mob Timer

A lightweight desktop timer for mob programming sessions. Add your team, choose how long each driver has, then start the rotation and keep every voice in the loop.

View project Latest Release

Why use Mobby

Clear rotation

Keep the selection order visible, randomize it when needed, and move people in and out without losing track of the session.

Driver focus

Each turn has a fixed driving window, with a strong prompt when it expires so the next person can take over without friction.

Built-in breaks

Configure break timing and length, skip them when needed, and automatically resume the next driver's turn after the break ends.

Rotation list

  • Sit out: moves a mobber from the rotation to the “Potential mobbers” list without deleting them. If they were driving, the next mobber takes over.
  • Rejoin: moves a potential mobber back to the end of the rotation.
  • ×: deletes a mobber entirely, from either list.
  • Randomize order: shuffles the driver rotation list. The next driver becomes the first person in the randomized list. This button is only active when there are two or more participants.
  • Select: choose a participant as the current driver without changing the rotation order. This is available while the timer is stopped or paused; driver selection is disabled while a timer is running.

On a turn-expiry, break, break-end, or resume popup, select Choose driver to access the rotation list. Select a participant to set them as the current driver, then select Continue to popup to return to the same prompt. If the rotation is empty, rejoin or add a participant before continuing.

Skipping drivers

  • At the next-driver popup, press “Skip <name>” to pass over the selected driver. Each press moves to the following person in the rotation, then starts the turn with the driver you want.
  • When resuming a paused timer, pressing Start/Resume asks whether to resume the current driver or skip them. “Keep paused” or Esc leaves the timer paused.

Breaks

  • Time between breaks defaults to 50 minutes and break length defaults to 10 minutes; both are configurable in minutes.
  • Once the driving time since the last break reaches the break interval, the next time a driver finishes, the prompt offers a break instead of the next driver. Otherwise the regular next-driver prompt appears.
  • When the break ends, a prompt brings the next driver’s session to the front.
  • Skip break: the break prompt also offers “Skip break”. It skips the break, resets the time until the next break, and starts the next driver’s turn.

Your participant list and timer settings are saved locally in the app.
